# سيارتي العراق

هذا المشروع هو موقع Django باسم **سيارتي العراق**. وظيفته الأساسية مساعدة المستخدم العراقي على معرفة مواصفات سيارته، الزيت المناسب، الفلاتر، الأوكتان، حاسبة خلط الوقود، وكلاء الزيوت وقطع الغيار، وصفحة الصيانة والأعطال.

إذا تريد تفهم المشروع من الصفر وكأنك تتعلمه خطوة بخطوة، اقرأ الملف:

`docs/PROJECT_GUIDE_AR.md`

## أهم الميزات

- بحث مخصص صارم يربط المحرك بالماركة والموديل والسنة وسوق المواصفات.
- دمج صفوف الفئات والمحركات التابعة للسيارة والسنة والسوق في بطاقة سيارة واحدة.
- عرض مواصفات السيارة بمستويات ثقة: موثق، عام، وتحقق قبل الشراء.
- عرض الزيت، الوقود، الأوكتان، وسعة الزيت كبيانات أساسية، مع وضع الإطارات والبلكات والبطارية والكير ضمن تفاصيل تحتاج تحقق قبل الشراء.
- حاسبة خلط الوقود حسب رقم الأوكتان.
- صفحة صيانة وأعطال:
  - مستكشف أعراض الأعطال.
  - بطاقة صيانة حسب الممشى.
  - ملاحظات ثابتة مهمة عن أجواء العراق.
- وكلاء الزيوت وقطع الغيار.
- نظام إعلانات وبنرات.
- أكواد خصم للرعاة.
- لوحة خدمات للرعاة.
- إعدادات عامة تتحكم بظهور أو قفل بطاقات الواجهة مع رسالة مخصصة عند الضغط.
- PWA: يمكن تثبيت الموقع كتطبيق على الهاتف، وعلى iPhone يتم التثبيت من Safari عبر المشاركة ثم الإضافة إلى الشاشة الرئيسية.
- sitemap نظيف يركز على الصفحات الأساسية وصفحات الأعراض، ولا يدرج روابط توصيات السيارات الفردية مؤقتاً.

## أوامر مهمة

تشغيل الاختبارات:

```bash
python manage.py test --settings=config.settings
```

إنشاء migrations بعد تعديل الموديلات:

```bash
python manage.py makemigrations cars --settings=config.settings
```

تطبيق migrations:

```bash
python manage.py migrate --settings=config.settings
```

تشغيل السيرفر المحلي:

```bash
python manage.py runserver --settings=config.settings
```

فحص جاهزية الإنتاج:

```bash
python manage.py check --deploy --settings=config.settings
```

هذا الفحص يفشل إذا نُسيت إعدادات أساسية مثل `DATABASE_URL` أو النسخ الاحتياطي أو الدومين العام.

استبدال بيانات السيارات بالكامل من ملف Excel بنفس الهيكل الحالي:

```bash
python manage.py reset_car_specifications /path/to/car-specifications.xlsx --yes --settings=config.settings
```

## بطاقات الواجهة والقفل

من لوحة الإدارة يمكن قفل بطاقات الواجهة الرئيسية مع بقائها ظاهرة وإظهار رسالة عند الضغط. البطاقات المدعومة حالياً:

- البحث عن السيارة.
- حاسبة الوقود.
- الوكلاء.
- الصيانة والأعطال.

إذا كان القفل غير مفعل تفتح البطاقة رابطها الطبيعي، وإذا كان القفل مفعل تظهر رسالة القفل فقط.

## إعلانات البطاقات

الإعلانات مفصولة حسب البطاقة:

- إعلان `gateway_card` يمكن ربطه ببطاقة رئيسية محددة: البحث، حاسبة الوقود، الوكلاء، أو الصيانة.
- إذا تُرك الاستهداف فارغاً، يصبح الإعلان احتياطياً عاماً لبطاقات الرئيسية التي لا تملك إعلاناً مخصصاً.
- إعلان `dealer_card` يمكن ربطه بوكيل محدد.
- إذا تُرك الوكيل فارغاً، يصبح الإعلان احتياطياً عاماً للوكلاء الذين لا يملكون إعلاناً مخصصاً.

## متطلبات الإنتاج

قبل النشر الفعلي يجب ضبط القيم التالية في `.env` أو لوحة البيئة:

- `SECRET_KEY`: مفتاح إنتاج حقيقي.
- `DEBUG=False`.
- `ALLOWED_HOSTS`: الدومينات الفعلية مثل `sayarti.org,www.sayarti.org`.
- `CSRF_TRUSTED_ORIGINS`: نفس الدومينات مع `https://`.
- `ADMIN_URL`: مسار خاص للوحة التحكم، ولا يُترك `admin/`.
- `DATABASE_URL`: رابط PostgreSQL، لا تعتمد على SQLite في الإنتاج.
- `BACKUP_GITHUB_REPO` و`GITHUB_BACKUP_TOKEN` و`BACKUP_ENCRYPTION_PASSPHRASE`: لتفعيل النسخ الاحتياطي المشفر.
- `DEEPSEEK_API_KEY`: مزود الذكاء الوحيد للبحث الذكي.

## النسخ الاحتياطي والاسترجاع

تشغيل نسخة احتياطية يدوياً على السيرفر:

```bash
cd /var/www/sayarti
bash scripts/backup.sh
```

السكربت ينسخ الشفرة، `.env`، قاعدة البيانات، و`media`. عند ضبط `BACKUP_ENCRYPTION_PASSPHRASE` يرفع الملف مشفراً بامتداد `.enc` إلى مستودع GitHub خاص.

فك التشفير للاسترجاع:

```bash
openssl enc -d -aes-256-cbc -pbkdf2 -in backup.tar.gz.enc -out backup.tar.gz -pass pass:"YOUR_BACKUP_ENCRYPTION_PASSPHRASE"
tar -xzf backup.tar.gz
```

استرجاع PostgreSQL من dump داخل النسخة:

```bash
pg_restore --clean --if-exists --no-owner --no-privileges -d "$DATABASE_URL" artifact/pg_dump/*.dump
```

## منطق الثقة في بيانات السيارة

نتائج البحث وصفحة التوصيات لا تعرض كل البيانات بنفس الثقة. التقسيم الحالي:

- `موثق`: السنة، نوع الوقود، الأوكتان، لزوجة زيت المحرك، ماركات الزيت، وسعة زيت المحرك عند توفرها.
- `عام`: لزوجة الزيت بعد 100 ألف كم وملاحظات الاستخدام الشاق في العراق.
- `تحقق قبل الشراء`: الإطارات، البلكات، البطارية، نوع الكير، زيت الكير، كود المحرك، الفئة، والتوصيات التفصيلية.

الهدف أن تبقى البطاقة بسيطة وموثوقة، ولا تعرض القطع الحساسة كحقيقة نهائية بدون تحقق من رقم الشاصي أو دليل الشركة.

## قواعد البحث وتجميع النتائج

- البحث المخصص يتطلب الماركة والموديل والسنة ومواصفات المنطقة قبل إتاحة اقتراحات المحرك.
- نوع المحرك والمحرك نفسه اختياريان. المحرك يظهر كقائمة منسدلة تُملأ فقط بمحركات الماركة والموديل والسنة والسوق المختارين، ويثبت النظام نوعه تلقائياً عند الاختيار.
- الخادم يرفض تطبيق فلتر محرك إذا أُرسل منفصلاً عن الماركة والموديل والسنة والمنطقة، حتى عند تعديل رابط البحث يدوياً.
- مفتاح بطاقة النتيجة هو: الماركة + الموديل + السنة + مواصفات المنطقة.
- اختلاف الفئة `Trim` لا ينشئ بطاقة جديدة، والفئة لا تظهر في نموذج البحث.
- إذا لم يحدد المستخدم محركاً وكانت هناك عدة محركات، تعرض البطاقة رسالة اختيار ولا تعرض التوصيات مجتمعة.
- يظهر محرك واحد وتوصياته في كل مرة؛ وإذا اختير المحرك من نموذج البحث تفتح توصيته مباشرة.
- مواصفات المنطقة حقل إجباري في المتصفح والخادم، ولا تعرض نتائج سيارة من دون تحديد السوق.
- إذا اختلفت توصيات موثقة بين المحركات، تبقى كل توصية مرتبطة بمحركها داخل البطاقة ولا تُعمم على بقية المحركات.
- اسم المحرك الكامل، بما فيه نظام الدفع FWD/AWD أو وصف المنظومة، جزء من مفتاح الفصل؛ لا تُدمج محركات متشابهة في السعة أو الكود إذا اختلف وصفها الكامل.
- بطاقة المحرك ترتب المعلومات بصرياً: لزوجة الزيت في شريط أفقي بارز، ثم السعة والماركات، ثم الوقود والأوكتان في صف مستقل، وتبقى المواصفات الثانوية داخل التفاصيل الإضافية.
- جدول `CarSpecification` وهيكل استيراد وتصدير Excel لم يتغيرا بسبب هذا التجميع؛ الدمج يحدث عند العرض فقط.
- عدد أعمدة Excel وترتيبها لم يتغيرا، لكن حقول المواصفات الوصفية لم تعد مقيدة بحد 50 حرفاً؛ تشمل الزيت والوقود والأوكتان والإطارات والبطارية والمحرك وناقل الحركة.

## حالة بيانات السيارات

بيانات السيارات تُدار من جدول `CarSpecification` ومن مستورد ومصدّر Excel الحاليين. لا يجوز استنتاج توصية عامة من حجم المحرك وحده؛ نطاق كل صف وتوصية تحدده السنة والسوق ونوع المحرك، ثم تجمع الواجهة الصفوف المتصلة في بطاقة واحدة من دون تعديل البيانات الأصلية.

## قاعدة Excel في لوحة الإدارة

- كل جدول بيانات يُدخل يدوياً يوفّر ثلاثة أزرار: تنزيل نموذج، استيراد Excel، وتقرير Excel.
- تشمل الدورة الموحدة حالياً: الشركات الراعية، أكواد الخصم، البنرات، الوكلاء، أعراض الأعطال وأسبابها، ومهام الصيانة. يبقى استيراد وتصدير السيارات بآليته ذات 23 حقلاً دون تغيير.
- عدادات تثبيت التطبيق ونقرات الوكلاء بيانات آلية؛ لذلك لها تقرير Excel فقط ولا تقبل الاستيراد.
- إعدادات الموقع، كلمات المرور، مفاتيح API وبيانات Analytics السرية لا تُصدّر ولا تُستورد عبر Excel.
- استيراد البنرات يدير البيانات النصية والروابط والاستهداف، أما ملفات الصور نفسها فتبقى في تخزين الوسائط ولا تُرفع من خلية Excel.

## حالة الأمان الحالية

- فحص Django للإنتاج يمر عند توفير متغيرات البيئة الإلزامية.
- فحص الحزم بـ `pip-audit` لا يسجل ثغرات معروفة في القيود الحالية.
- الحد الأدنى لـ Pillow هو `12.3.0` بسبب إصلاحات أمنية في الإصدارات الأقدم.
- توليد أكواد الخصم يستخدم مولداً عشوائياً آمناً تشفيرياً.
- عامل التطبيق يخزن الأصول المستخدمة فعلياً فقط، وأهمها `static/css/app.css`.
